# Contributing

Contributing to this repository follows the same standard process as the open source world.

## Before PR

1. File an issue in [Jira](https://jira.jsguru.com/browse/ICSAUTO).
2. Have a design discussion or architecture review with [team members](.github/CODEOWNERS).
3. Fork the repository into your personal GitHub organization.
4. Clone the repo from your fork.
5. Make your local changes, write your tests.
6. Commit and push your changes to your fork.
7. Create a pull request.

## During PR

1. After PR build is successful, request [team members](.github/CODEOWNERS) to review the PR.
2. Resolve issues.
3. Request [team members](.github/CODEOWNERS) to merge changes into master.

## After PR

1. Validate your changes in pre-prod after the code is merged and deployed.
